# 个人作品网站需求文档（Proposal）

> 项目代号：风花诗酒茶个人网站  
> 文档版本：v1.0  
> 文档日期：2026-07-27  
> 当前状态：需求已确认，可进入原型与开发阶段

## 1. 项目概述

本项目旨在开发一个面向普通访客的个人作品网站，用于求职展示与个人介绍。网站围绕个人信息、摄影作品、科研成果和联系方式展开，以高质量摄影内容作为主要视觉资产。

网站需要同时支持中文和英文，覆盖桌面、平板和手机，并在不影响浏览效率的前提下提供接近 Unreal Engine 官网气质的开场动画、沉浸式视觉布局和流畅交互。

当前阶段只需要生成可供网站所有者自行查看和维护的开发预览版本，不要求立即购买域名、完成域名实名认证或办理 ICP 备案。

## 2. 项目目标

### 2.1 核心目标

1. 清晰介绍网站所有者的个人身份、教育背景、获奖经历和联系信息。
2. 以具有视觉吸引力且高性能的方式展示风光与人像摄影作品。
3. 展示科研项目及其简介、项目图片和论文成果。
4. 允许网站所有者通过浏览器管理后台维护所有公开内容。
5. 在中文和英文之间快速切换，并提供完整一致的双语体验。
6. 在桌面、平板和手机上提供完整、流畅且易用的浏览体验。

### 2.2 成功标准

- 普通访客能够快速理解网站所有者的身份和作品方向。
- 访客可以在不跳转页面的情况下放大摄影作品并连续浏览。
- 访客可以通过居中弹窗查看科研项目的完整内容。
- 网站所有者无需修改代码，即可通过浏览器后台更新全部内容。
- 约 100 张摄影作品不会造成首屏一次性加载或明显卡顿。
- 中英文、深浅色和三类设备上的体验保持一致。

## 3. 目标用户

### 3.1 主要用户

普通访客，包括希望了解网站所有者个人背景、摄影作品或科研经历的人。

### 3.2 管理用户

网站所有者本人。后台不支持多人协作，不设置访客注册、会员或其他管理角色。

## 6. 功能需求

### 6.1 首页

首页需要建立清晰、具有视觉冲击力的个人形象，并采用参考 Unreal Engine 官网的内容节奏：大尺寸标题、沉浸式图片、充足留白、模块化内容区块及随滚动自然出现的内容。

#### 6.1.1 开场动画

- 每次进入或重新进入首页时播放。
- 总时长不超过 1 秒。
- 参考 Unreal Engine 官网的开场动感，但不得复制其 Logo、品牌资产或具体动效。
- 动画结束后自然进入首页首屏，不设置强制等待、视频广告或额外点击步骤。
- 动画加载失败或设备性能不足时，应直接进入页面，不影响正常浏览。
- 当操作系统开启“减少动态效果”时，自动使用简化的淡入效果。

#### 6.1.2 首页首屏

- 使用一张可在后台替换的代表性摄影作品作为核心视觉素材。
- 展示昵称“风花诗酒茶”和简短个人定位。
- 个人定位为“我关注人工智能、交互设计与人的感知，也持续用摄影记录日常经验。”，英文页面提供语义对应的英文版本。
- 首屏文字与图片必须在深浅色模式下保持足够对比度。

#### 6.1.3 首页内容区块

- 个人介绍：头像、简介和身份信息。
- 精选摄影：展示 5 张后台指定的精选照片。
- 精选科研：展示 3 个后台指定的科研项目。
- 简历摘要：教育经历、获奖经历和 PDF 简历下载入口。
- 联系方式：仅展示可点击的联系邮箱。

### 6.2 摄影作品

#### 6.2.1 分类与规模

- 分类固定为“风光”和“人像”。
- 初期摄影作品总量预计约 100 张，系统设计应允许继续增加。
- 每张照片只能属于一个或多个分类的规则由内容模型支持；初期后台界面默认要求至少选择一个分类。

#### 6.2.2 列表布局

- 分类页使用紧凑的 `4:3` 缩略图概览墙：桌面 5 列、平板 4 列、手机 3 列，便于快速比较不同作品；点击后在大图查看器中以未裁切的原始比例查看。
- 合集详情页使用保留照片原始宽高比、逐行两端对齐的相册流布局，避免瀑布流底边不齐。
- 首批只加载满足当前视口浏览所需的内容，其余作品分批加载。
- 图片进入视口前采用延迟加载，避免一次性下载全部照片。
- 加载更多内容时保持现有滚动位置，不产生明显页面跳动。
- 提供风光与人像分类切换，并清晰显示当前分类。

#### 6.2.3 排序与精选

- 后台可指定 5 张精选照片，并调整精选照片顺序。
- 首页只展示这 5 张精选照片。
- 摄影作品页中，已填写分类页排序编号的照片按编号由小到大展示；编号相同的作品采用稳定随机顺序。未编号作品排在最后，并按原有精选与拍摄时间规则回退排序。
- 拍摄时间精确到年月。

#### 6.2.4 大图查看器

- 点击任意照片后，以覆盖当前页面的大图查看器展示，不跳转到独立详情页。
- 支持放大查看。
- 支持上一张和下一张切换。
- 桌面端支持按钮与键盘方向键；移动端支持触控滑动。
- 支持点击关闭按钮、按 Esc 键或点击安全的背景区域关闭。
- 同时展示拍摄年月、城市级地点和文字介绍。
- 不展示相机、镜头、焦距、光圈等 EXIF 参数。
- 不添加水印，也不实现禁止下载功能。

### 6.3 科研成果

#### 6.3.1 项目列表

- 科研成果以项目卡片形式展示。
- 首页展示 3 个后台指定的精选项目。
- 科研成果栏目展示全部已发布项目。
- 项目不设置独立详情页。

#### 6.3.2 项目弹窗

- 点击项目卡片后打开居中弹窗。
- 弹窗展示项目名称、项目时间、项目简介、1 至 3 张项目图片以及论文名称。
- 论文只展示名称，不提供论文链接或 PDF 下载。
- 项目图片无需提供摄影作品同等级的放大查看器。
- 弹窗支持关闭按钮和 Esc 键关闭，并管理好键盘焦点。
- 移动端弹窗在保证可读性的前提下可接近全屏显示。

### 6.4 关于我 / CV

- About 页面展示头像、个人简介、研究兴趣与教育背景。
- 同页的 CV 区块提供作品集与个人简历下载；不再提供独立的简历导航入口。
- 作品集和个人简历各显示一张静态首页预览图，不在页面内打开 PDF 阅读器。
- PDF 文件由网站所有者提供，并作为静态文件更新。
- 网站不解析或翻译 PDF 内容。

### 6.5 联系方式

- 仅展示邮箱 Northstar_lzh@zju.edu.cn。
- 邮箱支持点击后调用设备默认邮件客户端。
- 不设置联系表单、手机号、社交媒体或第三方平台入口。

### 6.6 中英双语

- 默认语言为中文。
- 提供始终可见且易于理解的中英文切换入口。
- 个人简介、教育经历、获奖经历、摄影介绍和科研项目内容均由网站所有者分别提供中英文版本。
- 后台需要分别提供中文与英文字段，禁止使用自动机器翻译替代正式内容。
- 切换语言后尽量保留用户当前页面、分类和浏览位置。
- 导航、按钮、加载提示、空状态和错误提示均需双语覆盖。

### 6.7 深浅色主题

- 首次访问时跟随操作系统的深浅色设置。
- 提供手动切换按钮。
- 用户手动选择后，在后续访问中保持该选择。
- 两套主题均采用低饱和、少颜色的视觉策略。
- 摄影作品保持原始色彩，不使用改变照片观感的全局滤镜。

### 6.8 浏览器内容管理后台

后台仅供网站所有者使用，并应包含安全登录。开发预览阶段“不办理认证”仅指暂不进行域名实名认证与 ICP 备案，不代表后台可以取消身份验证。

后台需要支持：

- 编辑昵称、头像、个人简介、学校、身份标签和邮箱。
- 编辑中英文教育经历与获奖经历。
- 上传和替换 PDF 简历。
- 设置首页代表性摄影作品。
- 新增、编辑、删除和分类摄影作品。
- 设置 5 张精选摄影作品及其展示顺序。
- 新增、编辑和删除科研项目。
- 设置 3 个首页精选科研项目及其展示顺序。
- 上传图片时保留高清原图，并自动生成适合网页的多尺寸优化版本。
- 保存修改后立即更新公开页面，不设置独立审核、预览或定时发布流程。
- 对必填字段、图片数量和文件类型进行校验。

正常情况下，内容保存后应在较短时间内反映到网站；目标为 60 秒内完成内容刷新。

## 8. 视觉与交互规范

### 8.1 视觉方向

- 关键词：简洁、沉浸、克制、专业、摄影优先。
- 参考 Unreal Engine 官网的开场动画、首页排布、超大标题和滚动节奏。
- 参考只用于视觉语言和交互氛围，不复制其页面、素材或品牌识别。
- 除黑、白、中性色和必要的交互强调色外，不使用过多颜色。
- 通过字号、间距、图片尺度和动态节奏建立层级，而不是依赖多种颜色。

### 8.2 交互原则

- 动效服务于层级和反馈，不遮挡主要内容。
- 常规交互应在操作后立即得到视觉反馈。
- 页面转场、滚动出现和悬停效果保持短促、自然。
- 动画期间不得锁死滚动或导致按钮不可用。
- 所有动效均提供低性能设备和“减少动态效果”模式的降级方案。
- 触控设备不依赖悬停才能获得关键信息。

## 9. 响应式要求

### 9.1 桌面端

- 使用较大视觉画幅、完整导航和多列瀑布流。
- 大图查看器支持键盘操作。
- 科研弹窗保持合理最大宽度，避免文字行长过长。

### 9.2 平板端

- 保留全部内容和主题、语言切换功能。
- 根据屏幕宽度减少瀑布流列数。
- 导航可转为紧凑模式。

### 9.3 手机端

- 保持完整功能，不提供内容删减版。
- 采用单列或双列自适应瀑布流。
- 点击目标适合触控，正文无需缩放即可阅读。
- 大图查看器支持左右滑动，科研弹窗允许内部滚动。

## 10. 性能要求

- 首页只加载首屏与接近视口的必要图片。
- 摄影作品采用响应式图片尺寸，并优先输出 AVIF 或 WebP 等现代格式。
- 保存高清源文件，但不直接把高清源文件作为默认网页资源传输。
- 所有非首屏图片采用延迟加载。
- 图片加载前预留宽高比例，降低布局跳动。
- 摄影作品分批加载，不一次传输约 100 张图片。
- 开场动画代码和素材保持轻量，总播放时长不超过 1 秒。
- 在正常网络下，页面应先呈现可浏览内容，再补充非关键图片和动效。

## 11. 可访问性要求

- 图片提供中英文替代文本。
- 导航、主题切换、语言切换、弹窗和图片查看器均支持键盘操作。
- 弹窗打开后焦点进入弹窗，关闭后返回原触发元素。
- 文本和背景满足可读的对比度要求。
- 交互状态不能只用颜色表示。
- 尊重操作系统的“减少动态效果”设置。

## 12. 搜索、统计与隐私

- 不接入访问统计或用户行为分析工具。
- 不设置 Cookie 营销或广告追踪。
- 不进行专门的搜索引擎排名优化、关键词策略或增长功能。
- 不主动阻止正常搜索引擎访问；如未来希望完全不被收录，应另行增加 `noindex` 配置。
- 只公开需求中明确列出的个人信息。

## 13. 推荐技术方案

### 13.1 开发语言与前端

- **TypeScript**：作为主要开发语言，降低大型页面交互中的类型错误。
- **Next.js（React）**：负责页面结构、路由、服务端或静态渲染、图片优化和内容更新。
- **Tailwind CSS**：建立可维护的响应式设计与深浅色设计系统。
- **Motion**：实现轻量的开场、滚动出现、弹窗和页面过渡动画。
- **next-intl**：管理中文、英文界面文本和语言路由。
- **next-themes**：实现跟随系统并支持手动覆盖的深浅色模式。
- **React Photo Album 或同类稳定组件**：实现响应式瀑布流。
- **Yet Another React Lightbox 或同类稳定组件**：实现大图、缩放、键盘和触摸切换。

具体依赖版本在正式开发时锁定，并以当时的稳定版本为准。

### 13.2 内容管理

开发预览阶段推荐使用 **Sanity Studio**：

- 提供浏览器管理后台。
- 支持自定义内容模型、中英文字段、图片与文件上传。
- 支持图片裁切、转换和 CDN 分发。
- 免费计划当前适合个人小型项目，正式使用前仍需复核届时的额度与条款。

### 13.3 开发预览部署

开发预览阶段推荐使用 **Vercel**：

- 无需先购买域名即可获得预览地址。
- 不要求在开发阶段办理 ICP 备案。
- 可在代码更新后自动生成最新预览版本。
- 当前免费 Hobby 方案适用于个人、非商业项目，但正式上线前仍需复核条款和额度。

### 13.4 正式上线策略

由于主要访客位于中国大陆，正式上线前需要进行一次真实网络环境测试，再决定：

1. 继续使用境外或香港部署，接受不同地区可能存在的访问差异；或
2. 购买中国大陆云资源、实名域名并完成 ICP 备案，将前台与图片资源迁移或部署到大陆节点。

正式生产环境的域名、云服务商、备案和年度预算均不属于当前开发预览阶段的阻塞项。

## 14. 安全要求

- 管理后台只允许网站所有者登录。
- 不在前端代码中暴露后台写入密钥。
- 图片上传限制为常见安全格式，并限制异常文件体积。
- 简历上传只接受 PDF。
- 后台操作与内容接口使用 HTTPS。
- 对删除内容进行二次确认；如 CMS 支持历史版本，应保留恢复能力。
- 定期导出或备份结构化内容，避免单一平台故障导致内容丢失。

## 15. 不在本期范围内

- 访客注册、登录或会员功能。
- 联系表单、留言、评论和点赞。
- 社交媒体或第三方个人主页链接。
- 相机、镜头、焦距、光圈等摄影参数。
- 图片水印或防下载机制。
- 论文下载、论文外部链接或科研项目独立详情页。
- 站内搜索。
- 访问统计、广告或用户行为跟踪。
- 专门的搜索引擎优化工作。
- 自动机器翻译。
- 当前阶段的正式域名购买、ICP 备案和大陆生产部署。

## 16. 开发阶段建议

### 阶段一：视觉原型与设计系统

- 建立深浅色设计变量、字体层级、间距与动画规则。
- 制作首页首屏、摄影瀑布流、大图查看器和科研弹窗原型。
- 重点验证参考 Unreal Engine 官网的视觉节奏是否适合个人作品内容。

### 阶段二：内容后台与数据模型

- 配置个人资料、教育、获奖、摄影和科研项目模型。
- 完成中英文字段、精选数量和图片数量校验。
- 配置后台单用户登录及图片优化流程。

### 阶段三：核心页面开发

- 实现首页、摄影作品、科研成果、个人简历和联系方式。
- 实现瀑布流分批加载、大图查看器与科研居中弹窗。

### 阶段四：主题、语言与动效

- 完成中英文切换和默认中文逻辑。
- 完成跟随系统及手动切换的深浅色主题。
- 完成不超过 1 秒的首页开场动画和页面微交互。

### 阶段五：质量验证

- 检查桌面、平板和手机布局。
- 检查键盘操作、减少动态效果和弹窗焦点。
- 使用接近 100 张作品的数据量进行图片与滚动性能测试。
- 检查中英文内容完整性及深浅色对比度。

### 阶段六：开发预览交付

- 部署无需独立域名的预览版本。
- 配置网站所有者的后台账号。
- 提供简短的内容上传与维护说明。

## 17. 验收标准

### 17.1 首页

- [ ] 每次进入首页均播放不超过 1 秒的开场动画。
- [ ] 动画失败时不阻碍页面显示。
- [ ] 首页首屏使用后台可替换的代表性摄影作品。
- [ ] 首页展示 5 张精选照片和 3 个精选科研项目。
- [ ] 首页包含个人介绍、简历摘要和邮箱。

### 17.2 摄影作品

- [ ] 风光与人像分类可正常切换。
- [ ] 照片采用瀑布流并分批加载。
- [ ] 5 张精选照片优先展示，其余按拍摄年月由新到旧排序。
- [ ] 点击照片可打开大图、缩放和左右切换。
- [ ] 大图视图展示年月、城市和双语文字介绍。

### 17.3 科研成果

- [ ] 点击项目后打开居中弹窗，不跳转独立页面。
- [ ] 弹窗完整展示名称、时间、简介、1 至 3 张图片和论文名称。
- [ ] 弹窗在桌面和移动设备上均可关闭并正常滚动。

### 17.4 双语与主题

- [ ] 首次打开默认中文。
- [ ] 所有导航、状态和正式内容均有中英文版本。
- [ ] 首次主题跟随系统，且允许手动切换并记忆选择。

### 17.5 后台

- [ ] 网站所有者可在浏览器中编辑全部公开内容。
- [ ] 可上传照片、科研组图和 PDF 简历。
- [ ] 后台限制精选摄影作品最多 5 张、首页科研项目最多 3 个、单个科研项目图片最多 3 张。
- [ ] 保存修改后无需审核即可更新公开页面。
- [ ] 高清源图得到保留，前台使用自动生成的网页优化版本。

### 17.6 兼容与质量

- [ ] 桌面、平板和手机具有完整功能。
- [ ] 关键操作可通过键盘完成。
- [ ] “减少动态效果”模式下使用简化动画。
- [ ] 约 100 张摄影作品不会在首屏一次性加载。
