# M07 应用外壳与导航

## 模块目标

实现全站布局、桌面导航、移动菜单、语言开关和主题开关的组合，确保所有页面入口一致且键盘可用。

## 前置依赖

- M02 设计系统。
- M05 国际化。
- M06 主题系统。

## 最小任务

- [x] M07-T01 建立 `[locale]/layout.tsx`，接入消息、主题和全局设计系统 Provider。
- [x] M07-T02 定义首页、摄影、科研、简历和联系方式的导航配置，不在组件内部重复硬编码。
- [x] M07-T03 实现桌面导航，正确标识当前页面并包含语言、主题切换。
- [x] M07-T04 实现移动菜单，保留全部导航和切换功能。
- [x] M07-T05 实现菜单打开后的焦点进入、Tab 顺序、Esc 关闭和焦点恢复。
- [x] M07-T06 页面切换后自动关闭移动菜单。
- [x] M07-T07 实现“跳到主要内容”链接和唯一 `main` 内容容器。
- [x] M07-T08 联系方式入口指向当前语言首页的 `#contact`。
- [x] M07-T09 为桌面、平板、手机编写导航组件测试和视觉快照。
- [x] M07-T10 使用键盘完整走通菜单、语言切换和主题切换。

## 完成标准

- [x] 三类设备拥有相同的核心入口。
- [x] 导航不直接依赖任何摄影、科研或简历模块内部状态。
- [x] 移动菜单通过键盘和触摸均可完整操作。
