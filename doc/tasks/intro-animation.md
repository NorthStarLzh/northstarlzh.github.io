# M08 首页开场动画

## 模块目标

实现每次进入首页都会播放、总时长不超过 1 秒的轻量开场动画，并为减少动态效果、低性能和异常情况提供降级。

## 前置依赖

- M02 设计系统。
- M06 主题系统。

## 最小任务

- [x] M08-T01 将 `DetectPreference -> Playing/Reduced -> Complete` 状态机实现为独立纯逻辑并添加测试。
- [x] M08-T02 实现只使用轻量 DOM、`transform` 和 `opacity` 的动画覆盖层。
- [x] M08-T03 添加 1000ms 安全计时器，动画回调丢失时仍必须结束。
- [x] M08-T04 为 `prefers-reduced-motion` 实现短淡入，不执行明显位移动画。
- [x] M08-T05 确保首页内容在动画下方已经渲染且数据请求不因动画重复执行。
- [x] M08-T06 动画完成后卸载覆盖层并清理计时器、监听器。
- [x] M08-T07 确保动画期间不会永久锁定滚动或阻止安全超时后的交互。
- [x] M08-T08 仅在首页挂载组件，离开后再进入首页会重新播放。
- [x] M08-T09 添加正常、减少动态效果、安全超时、卸载和重复进入测试。
- [x] M08-T10 禁用 JavaScript 检查首页正文仍存在于服务端 HTML。

## 完成标准

- [x] 所有退出路径均在 1 秒内移除覆盖层。
- [x] 不加载视频、Canvas、3D 引擎或大体积动画素材。
- [x] 动画失败不影响页面正常使用。
