# M11 摄影查看器

## 模块目标

将摄影卡片点击事件接入可动态加载的大图查看器，支持缩放、连续切换、信息展示、键盘、触摸和焦点恢复。

## 前置依赖

- M01 基础契约与测试数据。
- M02 设计系统。
- M10 摄影列表。

## 最小任务

- [x] M11-T01 建立第三方 Lightbox 本地适配器，业务组件不得导入第三方类型。
- [x] M11-T02 定义 `photos`、`activeId`、`locale`、`onClose`、`onNearEnd` 公开接口。
- [x] M11-T03 使用照片 ID 派生当前索引，不把数组索引作为长期状态。
- [x] M11-T04 通过动态导入加载 Lightbox，未打开时不下载主包。
- [x] M11-T05 实现大图 URL 按需生成，尺寸高于缩略图但不默认请求原始文件。
- [x] M11-T06 实现放大、上一张、下一张、方向键、Esc 和移动端左右滑动。
- [x] M11-T07 在查看器中显示当前语言的拍摄年月、城市和介绍。
- [x] M11-T08 关闭后将焦点返回触发该照片的按钮。
- [x] M11-T09 接近已加载列表末尾时只触发一次 `onNearEnd` 预取下一批。
- [x] M11-T10 实现关闭按钮、可安全关闭的背景区域和动态导入失败提示。
- [x] M11-T11 在首页 5 张精选摄影和摄影页复用同一查看器接口。
- [x] M11-T12 添加 ID 定位、键盘、触摸、缩放、信息切换、预取、关闭和焦点测试。
- [x] M11-T13 在手机、平板和桌面完成连续浏览 E2E 测试。

> M11-T13：M15 的 Playwright 桌面、平板、手机项目已覆盖连续浏览、缩放、键盘/触摸切换、近尾预取、关闭与焦点恢复，三项目共 42 条全站旅程通过。

- [x] 查看器关闭后页面位置和焦点不丢失。
- [x] 初始页面包不包含完整 Lightbox 主包。
