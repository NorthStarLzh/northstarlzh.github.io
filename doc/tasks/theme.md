# M06 主题系统

## 模块目标

实现首次跟随系统、允许手动切换并记忆选择的深浅色主题，所有业务模块只消费语义颜色 Token。

## 前置依赖

- M01 基础契约与测试数据。
- M02 设计系统。

## 最小任务

- [x] M06-T01 配置 next-themes，支持 `system`、`light`、`dark` 三种内部状态。
- [x] M06-T02 将设计系统颜色映射为浅色和深色 CSS Token。
- [x] M06-T03 在根布局配置避免 Hydration 不一致和错误主题闪烁的必要属性。
- [x] M06-T04 实现主题切换按钮，明确显示当前主题并支持键盘操作。
- [x] M06-T05 将手动选择持久化，刷新后恢复。
- [x] M06-T06 验证处于 system 时响应操作系统主题变化，手动模式不被系统覆盖。
- [x] M06-T07 检查图片容器和全局样式未使用改变照片色彩的滤镜。
- [x] M06-T08 为主题解析、切换、持久化和系统变化添加自动测试。
- [x] M06-T09 对浅色和深色基础页面运行对比度检查与视觉快照。

## 完成标准

- [x] 首次访问跟随系统主题。
- [x] 手动选择在刷新后保持。
- [x] 摄影作品在两套主题中保持原始色彩。
