# M16 开发预览部署

## 模块目标

将通过全部质量检查的网站部署为仅用于开发查看的 Vercel Preview，配置 Sanity 开发数据集、后台账号、环境变量和维护说明，不购买正式域名或办理 ICP 备案。

## 前置依赖

- M01 至 M15 全部完成。

- [x] M16-T01 创建 `.env.example`，只列出变量名称、用途和获取方式，不填写真实值。
- [x] M16-T02 在本地验证缺失关键环境变量时给出明确错误，不静默连接错误数据集。
- [ ] M16-T03 创建 Vercel 项目并连接代码仓库的预览部署流程。
- [ ] M16-T04 在 Vercel 配置 Sanity 项目 ID、开发数据集、API 版本、站点来源和 Webhook 密钥。
- [ ] M16-T05 在 Sanity 配置允许的预览来源和签名发布 Webhook。
- [ ] M16-T06 邀请并验证唯一网站所有者后台账号，确认匿名用户无法写入。
- [ ] M16-T07 部署 Preview 并运行生产构建后的 Playwright 冒烟测试。
- [ ] M16-T08 在中国大陆常用网络环境实测首页、摄影缩略图、大图和后台访问，并记录结果；当前不据此承诺正式生产性能。

## 完成标准

- [ ] 网站所有者拥有可访问的预览地址和后台账号。
- [ ] 预览站通过核心冒烟测试，后台发布能刷新前台。
- [x] 真实密钥未进入仓库、文档或浏览器公开代码。
