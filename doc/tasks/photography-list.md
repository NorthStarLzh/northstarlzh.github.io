# M10 摄影列表

## 模块目标

实现风光/人像分类、首批服务端渲染、每批 20 张的游标分页、瀑布流和可靠的加载更多状态，不包含大图查看器内部实现。

## 前置依赖

- M01 基础契约与测试数据。
- M02 设计系统。
- M04 内容访问层。
- M05 国际化。
- 缩略图组件和图片资产映射分别由 M02、M04 提供；大图交互由 M11 接入。

## 最小任务

- [x] M10-T01 创建中英文摄影页路由并从 URL 读取 `category` 查询参数。
- [x] M10-T02 实现分类解析：合法值保留，缺失或非法值回退到 `landscape`。
- [x] M10-T03 实现分类切换控件，更新 URL 并支持浏览器前进/后退。
- [x] M10-T04 实现 `GET /api/photos` 参数校验和统一 JSON 响应类型。
- [x] M10-T05 实现不透明游标编码、解码和篡改/非法游标拒绝。
- [x] M10-T06 实现精选优先、精选顺序升序、其余拍摄年月降序和 ID 稳定排序。
- [x] M10-T07 首批在服务端加载最多 20 张，其余批次通过分页接口获取。
- [x] M10-T08 封装瀑布流适配器，使用图片宽高预留空间，并为卡片发出 `photoId` 点击事件。
- [x] M10-T09 配置响应式列数和 `sizes/srcset`，确保缩略图不请求高清源图。
- [x] M10-T10 使用 IntersectionObserver 实现自动加载，并提供无该 API 时的“加载更多”按钮。
- [x] M10-T11 使用 AbortController 取消分类切换前的旧请求，禁止风光和人像结果混入。
- [x] M10-T12 实现请求去重、照片 ID 去重、失败保留已有内容、重试和完成状态。
- [x] M10-T13 添加分类、游标、排序、分页、并发、取消、重试和无观察器降级测试。
- [x] M10-T14 使用约 100 张 Fixture 运行滚动集成测试，确认首屏不一次加载全部照片。

## 完成标准

- [x] 分类状态可通过 URL 恢复和分享。
- [x] 列表滚动加载稳定，无重复、串分类或明显布局跳动。
- [x] 查看器尚未接入时，点击事件仍能被组件测试独立验证。
