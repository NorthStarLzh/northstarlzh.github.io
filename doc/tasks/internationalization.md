# M05 国际化

## 模块目标

实现以 `/zh`、`/en` 为入口的稳定双语系统，默认中文，并保证语言切换不会丢失当前页面、摄影分类或锚点。

## 前置依赖

- M01 基础契约与测试数据。

## 最小任务

- [x] M05-T01 配置 next-intl 支持 `zh`、`en`，将 `/` 重定向到 `/zh`。
- [x] M05-T02 为非法语言段实现 404，避免静默回退到错误语言。
- [x] M05-T03 建立中文与英文消息文件，覆盖导航、按钮、加载、空状态、错误、下载和弹窗文案。
- [x] M05-T04 添加消息键一致性测试，任一语言缺少键时测试失败。
- [x] M05-T05 实现 `localize(LocalizedText, locale)`，缺失内容返回受控状态而非机器翻译。
- [x] M05-T06 实现语言 URL 替换函数，保留路径、查询参数和锚点。
- [x] M05-T07 实现语言切换按钮并提供当前语言和目标语言的可访问名称。
- [x] M05-T08 在测试路由验证 `/zh`、`/en`、摄影分类参数和 `#contact` 的切换行为。
- [x] M05-T09 验证日期和普通界面文本不意外混用另一语言。
- [x] M05-T10 运行单元、路由和组件测试。

## 完成标准

- [x] 根路径默认进入中文。
- [x] 所有系统文案存在中文和英文版本。
- [x] 切换语言保留当前访问上下文。
