# Shared components

Reusable layout, UI, and feedback components live here. UI primitives are business-agnostic and may not import from `src/features`.

- `layout`: `Container`, `Section`, `Stack`, and `Cluster`.
- `ui`: buttons, `AppImage`, the local `Dialog` adapter, and Skeletons.
- `feedback`: localized loading, empty, error, and retry states.
- `design-system`: a light/dark, three-viewport component showcase used by visual tests.
